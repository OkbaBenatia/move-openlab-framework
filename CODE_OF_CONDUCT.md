# Code of Conduct

MOVE OpenLab is a research tool built by and for people with different backgrounds, disciplines and levels of
experience. We want participation to be respectful, constructive and free from harassment for everyone.

## Expected behaviour

- Be respectful and considerate in issues, pull requests, reviews and discussions.
- Critique ideas, code and evidence — not people.
- Give credit: cite the work, data and methods you build on.
- Report results honestly; never present unverified or invented results as findings.
- Respect confidentiality: do not post other people's unpublished work, private data or credentials.

## Unacceptable behaviour

- Harassment, discrimination, insults or personal attacks.
- Sexualised language or imagery, intimidation or unwelcome attention.
- Publishing others' private information without explicit permission.
- Deliberately misleading claims about results, authorship or the behaviour of the software.

## Scope and enforcement

This code applies to all project spaces (repository, issues, pull requests, discussions) and to anyone representing
the project. The maintainer may edit or remove contributions and temporarily or permanently restrict participation
in response to violations.

Report incidents privately to the maintainer, Dr. Okba BEN ATIA, at okba.ben_atia@univ-fcomte.fr. Reports are
handled confidentially.
