# Manual acceptance — workflow checks

Steps a reviewer can follow in the running application (`./start-local.sh`, http://127.0.0.1:8765) to accept the
workflow corrections. Each line: where to click → what must be true. The same checks run automatically in
`scripts/e2e/workflow_acceptance.mjs` (against a copy of a data directory).

| # | Where to click | Accept when |
|---|---|---|
| 1 | Open *Montbéliard Demo — Baseline* | Left panel: title, status badges, Area, Mobility data, Scenario and one line "N/N runs validated · methods · scenarios"; *Experiment details* collapsed; the participant list starts in the first screen |
| 2 | *Experiment details* | Road network, sampling, lineage and identifiers; the open/closed state is remembered after a reload and a new sign-in |
| 3 | Map | Drivers: squares with a vehicle icon and colour (electric green bolt, combustion blue fuel drop, hybrid indigo leaf, plug-in teal plug); riders: person icons; pick-ups ▲ filled, drop-offs ▼ hollow; unmatched riders dashed grey; hover gives details; points at the same place fan out |
| 4 | **Compare** (opens on the *Methods* tab when the experiment has several methods) | A page for this experiment only: tick or untick methods; A is the reference (selector); Results (status, served, detour, runtime, CO₂, fleet, custom metrics, Δ) and Charts; Export table |
| 5 | Charts (any comparison) | Equal compact cards: 3 per row at full width, 2 at 160 % browser zoom, 1 on a phone; no horizontal scroll; hover tooltips; CSV · PNG · SVG; Enlarge (Esc closes) |
| 6 | **Compare** → *Experiments* tab → **Edit selection** → tick exactly one other → **Compare selected (2)** | Exactly A and B; the reference can be changed; incompatible candidates folded with *Why?*; hidden records only with the filter |
| 7 | Compare on an experiment with nothing comparable (e.g. a public benchmark run) | "No comparable experiment found." with *Compare methods in this experiment*, *Run another method on the same scenario*, *Reproduce this experiment* (once locked) |
| 8 | **+ Add method → Register my method → Register → Run with this method** | An extension (*… — Extension 1 (Method)*) runs on the same frozen scenarios; every run validated; the original unchanged |
| 9 | **Generate** → … → **Save & Run** | The Workspace opens on the new experiment within about a second, with *Queued › Preparing › Running methods › Validating › Results* and Cancel; a double click creates one experiment |
| 10 | Participants → **+ Driver** (then **+ Rider**) | The wizard opens on the participants step of a new scenario version with D(n+1) waiting for its start point; two map clicks place start and end; Route previews it; a point off the road network is refused; closing without Save stores nothing |
| 11 | Participants → **Randomize** | The editor opens with the *Randomize* dialog: counts, drivers per rider, vehicle shares (must add up to 100 %), seats, whole area or a rectangle, departures and windows, maximum detour, seed. **Generate** shows the drivers and riders on the map at once; the same seed gives the same places, another seed others; a rectangle without a road is refused with the reason. **Cancel** closes it; the seed field with **Randomize locations** below still redraws places only |
| 12 | **Run again** on a reproduction of a reproduction | Short title *… — Reproduction 2*, never nested; lineage under *Experiment details* |
| 13 | Library › **Benchmarks** → **Run the public benchmark** | Opens with progress; afterwards the run lists, per method, validated runs and runs equal to the min-cost-flow oracle optimum (Exact all) |
| 14 | Export one ZIP → second researcher → Import → Reproduce → Compare | Integrity verified before anything is stored; Reproduced; source, imported copy and reproduction distinguishable by category and title |
| 15 | Editor, participants step → drag **Rider** from the palette onto the map (or click it, then the map) → click the destination | The point is snapped to the road network; a small form opens (identifier, pick-up from / until, optional arrive by); **Save participant** adds the rider to the list and the map; a point outside the area is refused with the reason; **Undo** (or Ctrl+Z) takes the last change back |
| 16 | Click a driver or rider marker in the editor | The same form opens for that participant: vehicle type, seats, start and destination (*Set on map*), times; dragging the marker moves it (snapped), or is refused outside the area |
| 17 | Workspace → Results → **Choose metrics** | One dialog, groups *Validation, Optimization, Performance, Mobility and CO₂* (*ML evaluation* and *Custom metrics* when present); untick *Runtime* → **Apply**: the *Time* column leaves the table; *Select all*, *Deselect all* (Apply waits for one metric), *Reset to defaults*; with *Keep this choice for my account* the same metrics show in **Compare** (both tabs) and the charts |
| 18 | The Montbéliard demonstration, signed in as an administrator and then as a researcher | The same results table and the same **CO₂** card (avoided CO₂ against *everyone drives alone*, baseline and solution bars, per served rider) for both |
| 19 | **Compare** → *Charts* → tick two charts → **Export selected (ZIP)** | The count reads *2 of n charts selected*; the ZIP holds a PNG, an SVG and a CSV per chart, `manifest.json` and `README.txt`; each image shows the chart with its title, legend and provenance line. *Select all charts*, *Clear selection*; Bar, Grouped bar, Line, Scatter draw, and a type the data cannot support is disabled with the reason |
| 20 | **+ Add method** → register `plugins/example_scored_filter` → run it → **Compare** → *ML evaluation* | The exact method reads *Not applicable* with the reason; the example method reads *Not available — import evaluation evidence*. **Import evaluation evidence** → `examples/ml-evaluation/synthetic-binary-evidence.csv` with the metadata fields: the matrix reads TP 96 · FN 24 · FP 28 · TN 252; moving the threshold recomputes it and is marked as exploring, the recorded decision stays |
